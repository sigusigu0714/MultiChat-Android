# iPhone版との機能対応

| iPhone配布版の機能 | Android版 |
| --- | --- |
| MultiChat / OBS / コメントの3画面 | 同じ構成 |
| 最大10チャンネル、アカウント連携、公開視聴チャンネル | 同じサーバーAPIを使用 |
| Twitch・KICK・YouTube統合受信 | 対応 |
| 画像・バッジ・GIFエモート | Coil / Android画像デコーダーで表示 |
| 課金・購読・フォロー・レイド等 | 同じイベント形式を表示 |
| 重複除去、サービス別表示、自動スクロール | 対応 |
| Twitch・KICK送信、!fix | 対応。YouTube送信はiPhone版と同様に対象外 |
| OBS配信開始・停止、シーン・ソース切り替え | 同じリレーのコマンドを使用 |
| OBS切断時の操作無効化、自動再接続 | 対応 |
| Streamlabs / StreamElements | 透過WebViewで表示・音声再生 |
| アラート通知 | Androidの通知権限・通知チャンネルを使用 |
| 日本語読み上げ、速度、名前、除外ユーザー | AndroidのTTSを使用 |
| 日本語翻訳・原文併記 | ML Kitの端末内翻訳を使用 |
| 外観、文字サイズ、密度、スリープ防止 | 対応 |
| 接続設定JSON、確認後保存 | 同じ4項目の形式に対応 |
| 認証情報の保護 | Android KeystoreとAES-GCMを使用 |

OSの違いにより、画面の部品、ログインの戻り方、読み上げの声・速度、翻訳結果、通知の見え方はiPhoneと完全には一致しません。翻訳は初回に言語モデルのダウンロードが必要です。端末の日本語TTS音声が未設定の場合はAndroidの設定で追加します。

アプリを前面で使う想定です。バックグラウンドではチャット・OBS接続とアラートを停止し、復帰時に再接続します。画面を閉じたままの常時通知や常時配信監視を提供するものではありません。アラート表示をオフにしても前面ではウィジェットの音声は継続します。

自動テストは架空のデータとオフラインの画面を使用します。個別の運用サーバー、実アカウントのログイン・投稿、実際のOBS配信開始停止は、利用者の環境で確認が必要です。
