# プライバシーと配布

配布ファイルの接続先、アカウント、Twitch Client ID、OBSトークン、送信キーは空の状態です。開発者の運用サーバーや個人設定は含みません。署名証明書の主体名はMultiChat Distributionです。GitHubリポジトリの所有者はGitHub上で公開されます。

利用者が入力した設定・アカウント・認証情報はAndroid Keystoreの鍵でAES-GCM暗号化し、アプリ専用領域へ保存します。OSのクラウドバックアップと端末移行バックアップから除外します。OS・端末メーカーの動作まで含めた絶対的な秘密保持を保証するものではありません。

利用者のサーバーへチャット・認証・操作に必要な通信を行います。Twitchへの直接ログイン・送信、画像やアラート提供サービスの取得、Google ML Kitの言語モデル取得・SDK通信も行われます。翻訳処理自体は端末内です。TTSは端末に設定されたエンジンを使うため、音声提供者の設定や動作に依存します。

チャットは最大1000件をメモリー上に保持します。画像・アラートウィジェットにはライブラリやWebViewのキャッシュが使われることがあります。アラートURLは第三者に共有しないでください。秘密値をエラーログへ出力せず、TLSエラーの無視やHTTPへのフォールバックは行いません。

ソース・APKの文字列検査、空の初期設定、署名主体、暗号化保存を検証します。検査は既知の秘密情報パターンや誤同梱を見つけるもので、未知の脆弱性がないことを保証するものではありません。
